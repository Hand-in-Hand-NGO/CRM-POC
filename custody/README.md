# نظام العهد الإلكترونية

نظام مستقل لإدارة عهد الموظفين (لاب توب، موبايلات، شرائح، سيارات، أدوات…): تسجيل الأصناف، تسليمها للموظفين بسند، توقيع الموظف إلكترونيًا من موبايله، الارتجاع والنقل بين الموظفين، وطباعة السندات وبيان العهدة وإخلاء الطرف.

بنفس فونت وألوان نظام HandinHand CMS، وكل المكتبات موجودة داخل `assets/vendor`، فالنظام يعمل حتى على سيرفر داخلي بدون إنترنت.

## المميزات

- **ثلاثة أنواع أصناف، ولكل نوع حقوله الخاصة**:
  - **لاب توب** (`LT-00001`): الماركة، الموديل، S/N، المعالج، الرامات، نوع وسعة التخزين، حجم الشاشة، نظام التشغيل، عنوان MAC، نهاية الضمان، والملحقات المسلّمة (شاحن، شنطة، ماوس…).
  - **موبايل** (`MB-00001`): الماركة، الموديل، IMEI 1 و IMEI 2 (15 رقم)، السعة، الرامات، اللون، نهاية الضمان، والملحقات (شاحن، كابل، سماعة، جراب…).
  - **شريحة** (`SM-00001`): رقم الخط (يتأكد إنه رقم مصري صحيح)، الشبكة، رقم الشريحة ICCID، فاتورة أو كارت، عادية أو eSIM، الباقة وقيمتها الشهرية، باقة الإنترنت، والخط مسجل باسم مين.
  - مع كل صنف: القيمة، تاريخ الشراء، الحالة الفنية، والوضع (متاحة / مسلمة / صيانة / تالفة / مفقودة / مكهنة). الـ S/N والـ IMEI ورقم الخط ميتكرروش، ولكل صنف سجل كامل بكل اللي استلموه.
- **تبويبات حسب النوع** (الكل / اللاب توب / الموبايلات / الشرائح) في صفحة العهد وصفحة الأصناف: كل تبويب بيعرض أصناف النوع ده بس، بالأعمدة الخاصة بيه. وتصدير Excel بيطلع بكل حقول النوع المختار.
- **الموظفين**: بيانات الموظف، و"كارت عهدة" يعرض ما معه حاليًا وكل ما استلمه وسلّمه قبل كده.
- **تسليم عهدة**: اختيار موظف ومجموعة أصناف متاحة، وحالة كل صنف عند التسليم، فيُنشأ **سند تسليم** (`TS-2026-00001`).
- **التوقيع الإلكتروني**: لكل سند رابط خاص. تبعته للموظف (نسخ أو واتساب مباشرة)، أو تفتح "التوقيع الآن" على تابلت قدامه. الموظف يراجع الأصناف ونص الإقرار، ويكتب اسمه ويرسم توقيعه. بيتسجل الوقت والـ IP والجهاز. والرابط ممكن يتجدد لو اتبعت لحد غلط.
- **ارتجاع ونقل**: ارتجاع أصناف من موظف مع تحديد حالتها ووضعها بعد الاستلام (متاحة / صيانة / تالفة…)، أو نقلها مباشرة لموظف تاني (سند ارتجاع وسند تسليم في عملية واحدة).
- **الطباعة**: سند التسليم أو الارتجاع (A4) فيه توقيع الموظف الإلكتروني، و**بيان عهدة موظف**، و**شهادة إخلاء طرف** لو مفيش معاه عهدة.
- **لوحة متابعة**: إجمالي الأصناف وتوزيعها، والسندات اللي مستنية توقيع، وقيمة العهد القائمة، والعهد حسب القسم والتصنيف.
- **تصدير Excel** (CSV بالعربي) للعهد والأصناف والموظفين حسب الفلاتر.
- **المستخدمين والصلاحيات**: مدير النظام / مسؤول عهد / مشاهدة فقط، و**سجل عمليات** بكل حركة.

## المتطلبات

- PHP 7.3 أو أحدث، ومعاه `pdo_sqlite` (الافتراضي) أو `pdo_mysql`.
- Apache أو Nginx أو أي سيرفر يشغّل PHP.

## التركيب

1. ارفع محتوى فولدر `custody/` على السيرفر (مثلًا `public_html/custody` أو subdomain زي `custody.handinhand-eg.com`).
2. اعطِ صلاحية الكتابة لفولدر `data/` (`chmod 775 data` أو خليه مملوك لمستخدم السيرفر)، لأن فيه قاعدة البيانات.
3. افتح الرابط في المتصفح. الجداول بتتعمل لوحدها أول مرة.
4. ادخل بـ **admin / admin123**. النظام هيطلب منك تغيير كلمة المرور فورًا.
5. (اختياري) انسخ `config.local.example.php` باسم `config.local.php` وغيّر فيه:
   - `base_url`: الرابط العام للنظام، علشان روابط توقيع الموظفين تطلع صح لو السيرفر ورا proxy.
   - `db`: لو عايز MySQL بدل SQLite (اعمل قاعدة بيانات فاضية وحط بياناتها، والجداول هتتعمل لوحدها).
   - `ack_terms`: نص الإقرار اللي الموظف بيوقّع عليه.

> استخدم **HTTPS**، لأن الموظفين بيفتحوا رابط التوقيع من موبايلاتهم.

### Nginx

ملفات `.htaccess` بتحمي فولدر `data/` على Apache بس. على Nginx لازم تضيف ده، وإلا قاعدة البيانات هتبقى متاحة للتحميل:

```nginx
location ~ ^/custody/data/ { deny all; }
location ~ ^/custody/(config|config\.local|lib|schema)\.php$ { deny all; }
```

أو انقل قاعدة البيانات برة فولدر الموقع من `config.local.php`:

```php
'db' => ['sqlite_path' => '/var/lib/custody/custody.sqlite'],
```

## النسخ الاحتياطي

- **SQLite**: انسخ ملف `data/custody.sqlite` (ومعاه `-wal` و `-shm` لو موجودين) بشكل دوري.
- **MySQL**: `mysqldump custody > backup.sql`.

## تعديل حقول الأنواع

كل الأنواع وحقولها متعرّفة في ملف واحد هو `types.json`. لكل حقل: `label` (اسمه)، و`required` (إجباري ولا لأ)، و`options` (قائمة اختيار)، و`suggest` (اقتراحات والكتابة مفتوحة)، و`input` (`date` / `number` / `checks`)، و`pattern` (شرط تحقق). وكمان:

- `summary`: الحقول اللي بتظهر في عمود "المواصفات".
- `columns`: أعمدة الجدول لما تختار تبويب النوع.

تقدر تضيف حقل جديد أو تعدّل قائمة من غير ما تلمس الكود، بشرط إن الحقول دي تفضل زي ما هي: `brand` و `model` و `serial_no`. لو بتعدّل الديمو كمان، ابنيه تاني بـ `python3 custody-demo/build.py`.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.php` + `assets/app.js` | واجهة النظام (لوحة المتابعة، العهد، السندات، الأصناف، الموظفين، الإعدادات) |
| `api.php` | كل العمليات (JSON) مع التحقق من الصلاحيات وCSRF |
| `sign.php` | صفحة توقيع الموظف (عامة بالرابط الخاص بكل سند) |
| `print.php` | طباعة السندات وبيان العهدة وإخلاء الطرف |
| `types.json` | أنواع الأصناف (لاب توب / موبايل / شريحة) وحقول كل نوع |
| `lib.php` / `schema.php` / `config.php` | قاعدة البيانات والجلسات والإعدادات. قاعدة البيانات القديمة بتتحدّث لوحدها |
| `assets/theme.css` | فونت وألوان HandinHand CMS |
| `assets/vendor/` | jQuery 2.1.4، Bootstrap 3.3.7 + RTL، Font Awesome 4.7، Select2 4.0.13، خط Noto Kufi Arabic |
