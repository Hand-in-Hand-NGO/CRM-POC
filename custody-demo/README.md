# نسخة تجريبية من نظام العهد

`custody-demo.html` ملف واحد يفتح بالدبل كليك من غير سيرفر ولا إنترنت. فيه نفس واجهة نظام `custody/` ومعاه بيانات تجريبية، والبيانات بتتحفظ في المتصفح بس.

الملف بيتعمل **تلقائيًا من ملفات السيستم الحقيقي** (`custody/index.php` و `assets/app.js` و `app.css` و `theme.css`). أي تعديل يبقى في ملفات `custody/` الأول، وبعدين تبني الديمو تاني:

```bash
python3 custody-demo/build.py
```

- `demo-api.js`: بديل `api.php` جوه المتصفح، وفيه البيانات التجريبية وصفحة التوقيع والطباعة. لو اتضاف action جديد في `api.php` لازم يتضاف هنا كمان.
- زرار ↺ في الهيدر بيرجّع البيانات التجريبية للبداية.
